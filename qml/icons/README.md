# Иконки интерфейса

Символические иконки взяты из темы **Breeze** (KDE), пакет `breeze-icons`,
файлы `*-symbolic.svg` размера 22 (для `password.svg` — `dialog-password`).

- Лицензия: **LGPL-3.0-or-later** (см. `/usr/share/doc/breeze-icons/`).
- Иконки монохромные; в интерфейсе они перекрашиваются в цвет темы
  компонентом `qml/components/MIcon.qml` (`MultiEffect.colorization`),
  поэтому отдельные светлые и тёмные версии не нужны.
