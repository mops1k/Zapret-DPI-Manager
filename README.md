# Zapret DPI Manager 2.0

Служба Zapret DPI основывается на разработке https://github.com/ImMALWARE. Большое ему спасибо за создание!
Стратегии и некоторые доработки берутся из версии Zapret для Windows от [Flowseal](https://github.com/Flowseal/zapret-discord-youtube)

Проект развивается в форке [mops1k/Zapret-DPI-Manager](https://github.com/mops1k/Zapret-DPI-Manager): исходный репозиторий автора больше не обновляется, поэтому свежие стратегии, списки домен/IP, payload-бинарники и обновления службы выходят здесь.

## Назначение

**Zapret DPI Manager 2.0** — это графическая оболочка для службы Zapret на Linux и SteamOS. Она нужна, чтобы обходить ограничения на уровне DPI (типичный сценарий — недоступность отдельных сайтов и сервисов у конкретного провайдера) **без ручного редактирования конфигов в терминале**: включение и перезапуск службы, выбор или подбор стратегии, списки доменов и IP, DNS и другие настройки собраны в одном окне.

## Преимущества

- **Простой старт** — управление службой и автозапуском с главного экрана, пароль sudo запрашивается только когда он действительно нужен (в том числе с опцией запоминания).
- **Автоподбор стратегии** — программа может сама прогнать тесты по готовым стратегиям, выбрать наиболее удачную для вашей сети и применить её, а в списке готовых стратегий пометить подходящие **звёздочкой (⭐)**.
- **Дополнительные инструменты** — hostlist и IPSet, свои DNS, разблокировка сервисов через hosts, проверка соединения с текущей стратегией, **Game Filter** (игровые пресеты и сужение правил по портам).
- **Стратегии из BB DPI** — строку пользовательской стратегии из BB DPI (ByeByeDPI) можно вставить в приложение: она переводится в параметры nfqws, проверяется движком и применяется как готовая стратегия.
- **Актуальные данные обхода** — стратегии, списки доменов и IP, payload-бинарники и движок nfqws синхронизируются с актуальным набором Flowseal.

Полное описание интерфейса и сценариев — в файле [docs/user-guide-zapret-dpi-manager-steam-deck-ru.md](docs/user-guide-zapret-dpi-manager-steam-deck-ru.md).

## Установка
### SteamOS
Для работы вам понадобится sudo пароль. Его можно установить через консоль командой `passwd`

1. Скачать ярлык [Zepret_Manager_V2_Install.desktop](https://github.com/mops1k/Zapret-DPI-Manager/blob/main/Zepret_Manager_V2_Install.desktop) 
2. Запустить ярлык. Ярлык сам скачает установщик, распакует его и запустит
3. Ввести sudo пароль, когда появится окно для ввода пароля
4. Дождаться окончания установки

### Другие ОС
Для работы вам понадобится sudo пароль. Его можно установить через консоль командой `passwd`

1. Скачать архив установщика [install_zapret.tar.gz](https://cdn.jsdelivr.net/gh/mops1k/Zapret-DPI-Manager@main/install_zapret.tar.gz)
   Если зеркало не открывается, тот же файл берётся из архива репозитория (только хосты GitHub):
   ```bash
   curl -fsSL https://codeload.github.com/mops1k/Zapret-DPI-Manager/tar.gz/refs/heads/main -o /tmp/repo.tar.gz \
     && tar -xzf /tmp/repo.tar.gz -O --wildcards '*/install_zapret.tar.gz' > install_zapret.tar.gz
   ```
2. Распаковать в удобном месте
3. Запустить install_zapret.sh и следовать шагам установщика

Сама программа находится по пути `/home/%USER%/Zapret_DPI_Manager` - не удалять
Служба устанавливается в папку `/opt/zapret`.

### Локальная установка без релиза (для проверки)

Если релиз ещё не опубликован (страница Releases пуста), пакеты собираются локально:

1. `tools/build_release.sh` — создаёт `dist/Zapret_DPI_Manager.tar.gz` (полный пакет),
   `dist/zapret_updater.tar.gz` (для автообновления) и пересобирает `install_zapret.tar.gz`
   из `installer/install_zapret.sh`.
2. Распакуйте `dist/Zapret_DPI_Manager.tar.gz` в `~/Zapret_DPI_Manager` и положите нужную
   стратегию в `config.txt` (файл из `files/strategy/`).
3. Служба ставится из менеджера (пункт **«Обновить Zapret»**) или вручную: скопируйте
   `zapret/system/*` и `zapret/bins/<arch>/nfqws` в `/opt/zapret`, затем запустите
   `sudo /opt/zapret/starter.sh`.

### Обновление по частям: приложение, стратегии, движок

В окне **«Обновить Zapret»** три отдельные кнопки — каждую можно нажимать независимо.

- **«Обновить приложение»** — проверяет версию и, если есть новее, обновляет менеджер
  и службу целиком (с окном прогресса и перезапуском программы).
- **«Обновить стратегии»** — берёт стратегии напрямую из `Flowseal/zapret-discord-youtube`:
  скачивает архив ветки `main`, конвертирует `.bat`-файлы в формат менеджера
  (`core/flowseal_convert.py`), докладывает недостающие payload'ы в `files/bin`, а списки
  в `files/lists` **дополняет** новыми строками (ваши строки и `*_user.txt` не удаляются).
- **«Обновить движок»** — обновляет nfqws из `ImMALWARE/zapret-linux-easy` для текущей
  архитектуры: скачанный бинарник проверяется запуском `--version`, затем заменяются
  `/opt/zapret/nfqws` и локальная копия `zapret/bins/<arch>/nfqws`.
- Перед записью делается резервная копия в `~/.cache/zapret_dpi_manager/`. Если служба
  Zapret была запущена, она перезапускается, чтобы применились новые списки и payload'ы.
- Если Flowseal добавит payload, плейсхолдера которого ещё нет в `starter.sh`, такая
  стратегия будет пропущена с пояснением в логе — для неё потребуется обновление приложения.

### Если `raw.githubusercontent.com` недоступен

В РФ `raw.githubusercontent.com` периодически не отвечает, хотя `github.com` открывается.
Проверка обновлений и загрузка стратегий/движка не привязаны к этому хосту: файл скачивается
цепочкой (`core/github_fetch.py`) — `raw` → `api.github.com` (сырой файл через GitHub API) →
архив `codeload.github.com` → зеркало → последняя удачная копия из
`~/.cache/zapret_dpi_manager/gh_cache`. Если не сработал ни один сетевой путь, обновление
возьмёт прошлую удачную копию вместо ошибки.

Установщик скачивается так же, без raw: ярлык `Zepret_Manager_V2_Install.desktop` берёт
`install_zapret.tar.gz` из архива репозитория `codeload.github.com`, а при отказе — с зеркала
jsDelivr; ссылка в разделе «Другие ОС» ведёт на jsDelivr, запасная команда через архив
репозитория указана там же.

Зеркало по умолчанию — `cdn.jsdelivr.net/gh/...`; переопределяется переменной окружения
`ZAPRET_GH_MIRROR` при запуске менеджера:

- `https://ghproxy.net/` — префиксное зеркало (префикс + raw-URL);
- `https://<хост>/{owner}/{repo}/{ref}/{path}` — свой шаблон;
- `off` — отключить зеркало, останутся только хосты GitHub и локальный кэш.

Логику цепочки без обращения к сети проверяет `python3 tools/check_github_fetch.py`.

### Пароль sudo

Пароль запрашивает системный диалог (`sudo -A` через `core/askpass.py`) — приложение его
не хранит. После ввода можно нажать **«Запомнить»**: тогда пароль сохранится в
`~/.cache/zapret_dpi_manager/sudo.cred` (права 0600, владелец — ваш пользователь).
Удалить его можно пунктом меню **«Забыть пароль sudo»**.

## Начало работы: автоподбор стратегии

Рекомендуется сначала подобрать стратегию под вашу сеть, а уже потом при необходимости тонко настроить списки и DNS.

1. На главном экране нажмите иконку **настроек (шестерёнка ⚙️)** вверху.
2. Выберите пункт **«Сменить стратегию»**.
3. В окне выбора типа стратегии нажмите **«Автоподбор стратегии»**.
4. Дальше возможны два варианта:
   - **«Тестировать все стратегии»** — будут проверены все доступные готовые стратегии;
   - **«Выбрать стратегии для теста»** — вы сами отметите подмножество стратегий (удобно, если полный прогон занимает слишком много времени).
5. В окне **«Автоподбор стратегий»** при необходимости выберите **режим тестирования** («Стандартный» или «YouTube/Discord»), затем нажмите **«▶ Запустить тест»** и введите пароль **sudo**, если программа попросит.

По завершении теста программа **сама выставит наиболее удачную по результатам стратегию** (запишет конфиг и перезапустит службу Zapret). Список стратегий, которые тест признал подходящими для выбранного режима, сохраняется; в окне **«Выбрать готовую стратегию»** такие варианты отмечены **⭐** слева от названия — их можно выбрать вручную в любой момент. После теста обычно открывается **HTML-отчёт** с подробной статистикой; его можно снова открыть кнопкой **«📄 Отчёт»** в том же окне.

> Полный прогон всех стратегий может занять продолжительное время: не закрывайте окно теста до окончания, если не хотите прервать процесс.

## Стратегия из BB DPI

BB DPI (ByeByeDPI для Android) работает на движке **ciadpi** — это локальный SOCKS-прокси со своим синтаксисом опций, поэтому строку из BB DPI нельзя запустить в nfqws напрямую. Приложение переводит её в ближайшие по смыслу параметры nfqws:

1. **Сменить стратегию** → **«Стратегия из BB DPI»**.
2. Вставьте строку стратегии (например, `-s1 -d1 -f-1 -t8 -S`) и нажмите **«Преобразовать»**.
3. Проверьте предпросмотр и блок **«Замечания»**: приложение показывает, какие опции перенести не удалось.
4. При необходимости задайте имя стратегии и включите ограничение по нашему списку доменов, затем нажмите **«Сохранить и применять»**.

Что переносится: `-s/--split`, `-d/--disorder`, `-f/--fake`, `-t/--ttl`, `-S/--md5sig`, `-n/--fake-sni`, `-M/--mod-http`, `-H/--hosts`, `-j/--ipset`, `-V/--pf`, `-K/--proto`, `-a/--udp-fake` (приблизительно). Позиции вида `1:3:5` разворачиваются в список, `+s`/`+h` переводятся в маркеры `sniext`/`host`.

Чего нет в nfqws: `-o/--oob`, `-q/--disoob`, `-r/--tlsrec`, `-A/--auto` (автогруппы), `-L/-u/-y/-T` (кеш и таймауты авторежима), `-m/--tlsminor`, `-Y/--drop-sack`. Такие опции не переносятся, о чём приложение предупреждает перед применением. Результат сохраняется файлом в `files/strategy/`, поэтому потом его можно выбрать в окне **«Выбрать готовую стратегию»**.
